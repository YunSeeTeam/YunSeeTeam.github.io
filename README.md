# YunSee // CTF TEAM 官网

纯静态战队官网。**双击 `index.html` 即可运行**，不依赖任何构建工具、CDN 或网络请求。

设计参考 [Cloudflare-Showcase](https://github.com/ymh0000123/Cloudflare-Showcase) 的瑞士编辑风格
（1px 细线分割 / 等宽微标签 / 巨型字重标题 / 信号色块 / 加载幕布），内容与结构全部重写。

---

## 目录结构

```
YunSee-Site/
├─ index.html                  页面结构（含三处手写签名 SVG）
├─ assets/
│  ├─ css/style.css            设计令牌 + 全部组件与动效
│  ├─ images/                  合作伙伴 logo（文件名须为 ASCII）
│  └─ js/
│     ├─ data.js               ★ 站点全部内容都在这里，只改这个文件即可
│     └─ main.js               加载屏、渲染、筛选、表单、主题、滚动
└─ README.md
```

## 需要你修改的地方

打开 `assets/js/data.js`，全部内容集中在 7 个常量里：

| 常量 | 作用 |
| --- | --- |
| `SITE` | 战队名、标语、成立年份、**招新邮箱**、GitHub、QQ 群 |
| `FIELDS` | 方向定义（WEB / PWN / RE / CRYPTO / MISC / BC），同时驱动筛选与标签 |
| `CORE_MEMBERS` | 核心成员（含技能条百分比与外链） |
| `CLUB_MEMBERS` | 俱乐部成员名册 |
| `AWARDS` | 战队奖项（`level` 用 `国际 / 国家级 / 省级 / 行业`） |
| `PROJECTS` | 开源项目（`lang` 决定语言色点，可写 `Go + TypeScript` 这类复合串，取第一个能识别的语言取色） |
| `PARTNERS` | 合作伙伴（数组顺序即展示顺序） |
| `JOIN_NOTES` | 招新说明条目 |

成立年份只在 `SITE.founded` 维护一处，页眉、首屏统计块、页脚三处自动同步。

**上线前务必修改：**

```js
joinEmail:    'join@yunsee.team',       // 招新申请的收件邮箱
contactEmail: 'contact@yunsee.team',    // 对外联系邮箱
github:       'https://github.com/YunSee',
qqGroup:      '1145141919',
```

现有成员、奖项、项目均为示例占位数据，请全部替换为真实信息。

统计数字（成员总数、奖项数、国家级 / 国际 / 冠军数量）由 `main.js` 自动从数据推导，
**不需要手动维护**。

## 站点内容

| # | 章节 | 说明 |
| --- | --- | --- |
| 01 | 核心成员 | 卡片网格，含首字母色块、技能条（滚动到视野内逐条展开）、外链 |
| 02 | 俱乐部成员 | 名册表格 + 按方向筛选，切换时行逐条滑入 |
| 03 | 战队奖项 | 4 个统计块（数字滚动）+ 按年份倒序的奖项列表，**默认只展开最新 8 项** |
| 04 | 开源项目 | GitHub 仓库卡片，标签 + 语言色点（不显示 star 数：纯静态页不调 GitHub API，写死的数字会过期） |
| 05 | 合作伙伴 | logo 墙，默认去色、悬停整卡反色并释放原色 |
| 06 | 加入战队 | 邮箱表单，投递后唤起系统默认邮件客户端 |

### 合作伙伴 logo 怎么加

1. 把图片放进 `assets/images/`，**文件名必须用 ASCII**（中文名在部分静态托管上会因 URL 编码取不到图）；
2. 在 `data.js` 的 `PARTNERS` 里加一条，填 `name / en / logo / desc / tags / url`；
3. 建议正方形图片，卡片会按 1:1 `object-fit: cover` 裁切进白底托盘 —— 白底是固定的，
   这样深浅两个主题下三家 logo 的观感一致；
4. `url` 留空时卡片自动渲染成不可点击状态并显示「官网待补」，**不会产生死链**；填上地址后
   自动变成新窗口链接并出现 `↗` 角标。

### 成员数据的两个约定

- **多方向**：`field` 单方向写字符串，多方向写数组。核心成员与俱乐部成员都支持。
  ```js
  { handle: '世茶之火', field: ['RE', 'PWN'], ... }   // 俱乐部：两枚方向标签，RE / PWN 筛选下都会出现
  { handle: 'yuiiijuk', field: ['CRYPTO','IR','MISC'], ... }  // 核心：卡片右上角取第一个为主攻
  ```
- **占位链接**：核心成员的 `github` / `blog` 写 `'#'` 时，按钮**仍然显示**，
  但渲染成半透明不可点击的占位态（不会挂 `href="#"` 点一下跳回页首）。补上真实地址即自动变成可点链接。

### 奖项折叠

`main.js` 顶部的 `AWARD_PREVIEW = 8` 控制默认展示条数。超出部分收进折叠区，
用 `grid-template-rows: 0fr → 1fr` 做无渐变的平滑展开，展开时多出来的行按 60ms 阶梯淡入。
奖项总数不超过 8 条时，折叠按钮自动隐藏。

### 加入申请的工作方式

表单**不发送任何请求**。点击「投递申请」时：

1. 前端校验邮箱格式，不合法则内联报错；
2. 按填写内容拼装 `mailto:` 链接（收件人 = `SITE.joinEmail`，主题与正文自动生成）；
3. 触发跳转，唤起系统默认邮箱客户端并预填好内容，用户点发送即可；
4. 按钮进入「正在唤起 → 已唤起 ✓」状态，并提示手动发送的兜底邮箱。

## 动效清单

| 动效 | 位置 | 实现 |
| --- | --- | --- |
| **手写笔画签名** | 加载屏 / 页眉 / 页脚 | 6 段 SVG 路径 `pathLength="1"` + `stroke-dashoffset` 逐笔绘制 |
| 加载屏 | 首屏 | 左侧进度轨 + 跟随进度条的百分比读数 + 信号色幕布横向擦除 |
| 标题入场 | 首屏 | `YUNSEE` 逐字符从裁切框内上滑 |
| 滚动揭示 | 全站 | IntersectionObserver + 子元素 `--i` 阶梯延迟 |
| 数字滚动 | 首屏 / 奖项 | `requestAnimationFrame` + ease-out cubic |
| 卡片悬停 | 成员 / 项目 / 奖项 / 伙伴 | 纯色块 `scaleY` / `scaleX` 推入，文字整体反色 |
| logo 显色 | 合作伙伴 | 默认 `grayscale(1)`，悬停 .55s 缓动回原色并轻微放大 |
| 主题切换 | 页眉 | View Transitions API 圆形揭示（不支持时降级为淡入） |
| 页脚跑马灯 | 页脚 | 双轨 `translateX` 无缝循环 |

**加载屏时序**：首次访问约 2.35s（完整播完签名笔画），同会话内再次访问压缩到 0.95s。
随时可按 `ESC` 或点右下角「跳过」。后台标签页会有 9s 硬兜底强制放行。

## 设计约束

- **全站不使用任何渐变**。没有 `linear-gradient` / `radial-gradient` / `conic-gradient` /
  `repeating-*-gradient`。加载屏底纹用纯色 SVG 点阵 data-URI，骨架屏用纯色块位移代替微光扫描。
- **零外部依赖**。不加载 Web Font、不引 CDN、不发 `fetch`，因此可直接用 `file://` 打开，
  也可以扔进任意静态托管（GitHub Pages / Vercel / Cloudflare Pages）。
- **深浅双主题**。跟随系统偏好，手动切换后写入 `localStorage`。
- **响应式断点**：1240 / 1040 / 860 / 560px，移动端页眉收起为全屏菜单。
- **无障碍**：尊重 `prefers-reduced-motion`（关闭全部动画并直接显示完整签名）、
  焦点可见环、语义化表单标签与 ARIA 标注。

## 部署

静态托管直接上传整个文件夹即可，无需任何构建步骤。

```bash
# 本地预览（可选，直接双击 index.html 也可以）
python -m http.server 8080
```
